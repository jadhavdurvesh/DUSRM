# Foundational Research Register

This document tracks research areas, not conclusions.

| Area | Questions to investigate | Expected output |
|---|---|---|
| General systems theory | System, environment, boundary, hierarchy, emergence | Terminology and conceptual comparison |
| Systems engineering | Stakeholders, context, requirements, lifecycle, assurance | Mapping and scope analysis |
| Formal methods | State, transition systems, invariants, refinement | Candidate formal vocabulary |
| Distributed systems | Partial failure, causality, consistency, coordination | Applicability and limits |
| Operating-system and computer architecture | Processes, resources, execution, memory, hardware abstraction | Concept comparison |
| Networking reference models | Layering, service/interface/protocol distinctions | Layering lessons; avoid protocol duplication |
| Data and database theory | Identity, state, schema, transactions, persistence | Data-related concepts and boundaries |
| Robotics and cyber-physical systems | Physical environment, sensing, actuation, safety, timing | Cyber-physical validation criteria |

No literature review is complete yet. Add source citations, publication details, and a written comparison before using any area to justify a normative design decision.
