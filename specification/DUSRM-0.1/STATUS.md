# DUSRM 0.1 — Status

**Status:** Initial working draft; non-normative.

This draft establishes project scope, candidate dimensions, preliminary vocabulary, design principles, and research questions. It does not yet define a finalized architecture, layer model, formal semantics, or conformance requirements.

## What this draft establishes
- DUSRM is a universal conceptual reference framework, not an implementation technology.
- DUSRM must remain independent of individual DMJ APIs, protocols, engines, and products.
- The ten dimensions in the project README are hypotheses for research, not approved layers.
- Layering must be justified by the domain and supported by explicit responsibilities and interfaces.

## Required next work
1. Prior-art and terminology review.
2. Entity and relationship ontology.
3. Boundary and environment model.
4. Candidate structural representation comparison.
5. Cross-domain validation before freezing foundational semantics.
