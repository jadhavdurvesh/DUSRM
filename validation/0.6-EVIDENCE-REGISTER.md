## 4. Evidence limitations

- Repository documentation is a source of project-reported status, not proof that a build or test succeeds.
- Source code was not executed as part of this DUSRM validation exercise.
- FireBot's `CURRENT_STATE.md` identifies itself as a status snapshot dated 2026-10-11; changes after that date must be checked before relying on its maturity claims.
- The ANANTA workload connector is file-based JSONL in the inspected documentation. It is not evidence of live FireBot telemetry integration.
- DUSRM case-study files must be refreshed when these repositories or source documents change.
