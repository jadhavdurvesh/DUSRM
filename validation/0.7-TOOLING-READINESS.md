# DUSRM 0.7 — Tooling Readiness and Scope

**Status:** Proposal; non-normative

## 1. Purpose

This document defines what tooling is justified now and what remains premature.

## 2. Current artifacts

- JSON Schema Draft 2020-12 description-shape proposal, version 0.1-draft.
- GitHub Actions workflow for structural schema and fixture checks.
- Profile registry recording provisional compatibility status.
- One minimal valid example.
- One valid example demonstrating multi-layer realization.
- Five negative fixtures covering structural and semantic issues.
- Consistency-check catalogue separating schema, semantic, profile, evidence and human-review checks.
- Profile compatibility policy proposal.

## 3. What JSON Schema can check

It can validate JSON shape, required fields, basic value types, enumerations, and local object structure. It cannot by itself establish identifier uniqueness across multiple arrays, resolve cross-references, validate profile compatibility, prove invariants, judge evidence quality, or establish system safety.

## 4. What a future semantic validator would need

- schema-version selection;
- profile registry and compatibility lookup;
- global identifier indexes;
- reference resolution;
- relationship participant signatures;
- responsibility-to-layer and element-to-responsibility consistency;
- claim/evidence status rules;
- conformance check catalogue and output report.

## 5. Deferred tooling

Do not yet build a full editor, compiler, runtime, protocol, database, or automated certifier. A small reference validator may be justified after:
- the schema has been reviewed and tested against an independent JSON Schema implementation;
- profiles have explicit compatibility declarations;
- semantic checks have stable identifiers and test cases;
- reviewers agree that the underlying concepts are sufficiently stable.

## 6. Tooling safety boundary

A validator may say that a description is structurally valid or that specified checks passed. It must not say that the described system is safe, correct, secure, or fit for purpose unless those claims have been assessed under separate, appropriate criteria and evidence.
