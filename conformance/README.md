# Conformance Research

No normative conformance requirements have been adopted.

The current assessment framework evaluates a **DUSRM system description** at a declared version, profile, scope, and evidence level.

## Documents

- [DUSRM 0.6 assessment procedure](ASSESSMENT-PROCEDURE-0.6.md)
- [DUSRM 0.7 consistency-check catalogue](CONSISTENCY-CHECKS-0.7.md)
- [Conformance fixtures](fixtures/README.md)
- [Machine-readable description schema](../schema/README.md)

A CI workflow checks JSON Schema structure and fixture expectations. Cross-reference semantics, profile compatibility, evidence assessment, and human engineering review remain separate.

An assessment does not constitute safety certification, regulatory approval, or proof of fitness for purpose. It does not require use of any DMJ technology.
