# Conformance Research

No conformance requirements are normative yet.

The research task is to define what it means for an architecture description or engineering process to conform to DUSRM. Possible assessment areas include:
- Required concepts and definitions
- Explicit system context and boundaries
- Traceability of entities and relationships
- Consistency of state and operation descriptions
- Declared constraints and invariants
- Explicit interfaces and dependencies
- Assumptions, limitations, and failure conditions

Do not equate conformance with using a particular DMJ technology or software stack.
