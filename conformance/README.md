# Conformance Research

No normative conformance requirements have been adopted.

The current assessment framework is a draft and evaluates a **DUSRM system description** at a declared version, profile, scope, and evidence level.

See [DUSRM 0.6 Assessment Procedure](ASSESSMENT-PROCEDURE-0.6.md).

Proposed assessment levels:
- Level A — Vocabulary-compatible
- Level B — Structurally well-formed
- Level C — Behaviorally specified
- Level D — Formally assessed
- Level E — Implementation-evaluated

An assessment does not constitute safety certification, regulatory approval, or proof of fitness for purpose. It does not require the use of any DMJ technology.
