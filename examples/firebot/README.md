# FireBot Case Study

This folder will contain an informative DUSRM mapping of the integrated FireBot cyber-physical system.

The case study must consider the actual system boundary across robot hardware, sensors, actuators, power systems, embedded control, autonomy, communication, data, operator interaction, fleet coordination, and safety engineering.

Use verified FireBot design documents and repositories as evidence. Explicitly distinguish implemented, planned, and experimental capabilities. DUSRM is an architectural reference framework; it is not a substitute for hazard analysis, safety engineering, verification, or independent validation of safety-critical controls.
